## 已实现

## 实际界面核验

使用打包后的 Electron 应用，在隔离的 `.smoke/` Home 中执行：

- 模型配置界面、API Key 密码输入与本地使用入口。
- 创建中文调查，逐题保存年龄、作息和 7 小时自述，提前生成本地报告。
- 保存行动反馈，切换英文，再生成英文修订；旧中文报告保留原文。
- 经主进程 IPC 导入合成 XML，在界面选择对应睡眠，再生成报告：设备睡眠 390 分钟、自述 420 分钟分开保存；旧报告标记失效。
- 页面无水平溢出，打包版浏览器控制台 0 错误／0 警告。

根据截图收紧了最终报告布局：去掉重复大标题，摘要、AI 解读和一条行动优先，完整依据与反馈表单可展开，外层窗口不再重复滚动。这些变更通过组件顺序与布局回归；最后一次自动重开窗口受到执行环境限制，最终紧凑版的人工视觉确认待用户打开应用后完成。先前截图对应收紧前版本，不冒充最终效果图。

截图保存在本地 `pi-app/output/playwright/`，不提交版本库。文件选择器的系统对话框未自动点选；导入器与 IPC 已实际执行。

## 合成导入资源实测

执行 `npx tsx scripts/benchmark-import.ts`，当前 Windows 机器，Node 24.13.0，50,000 条合成记录、5 类指标各 10,000 条：

| 指标 | 实测 |
| --- | ---: |
| XML 文件 | 9.61 MiB |
| 首次导入 | 2.90 秒 |
| 再次导入 | 2.30 秒 |
| 第二次重复数／新增健康记录数 | 50,000／0 |
| 测试进程整个生命周期峰值 RSS | 133.61 MiB |
| 运行时 SQLite，包含 WAL／SHM | 最高 92.26 MiB |
| 关闭后数据库 | 51.63 MiB |

重复导入保留新的来源关联，所以数据库仍会增长。峰值包含 Node／tsx、数据生成和两轮导入，不是纯解析器的增量内存；此结果不能代替真实 Apple Health 大 ZIP 测量。

## 明确的产品限制

所有总分与维度分暂不计算，界面说明评分规则仍待验证。不会用临时阈值产生一个看似精确的分数。自述可生成本地简报；AI 个性化解释需要连接模型。

主要睡眠、午睡和片段均可选。90 分钟间隔只用于发现候选，用户可以修正范围。来源未选、卧床边界不可靠或指标缺失时，对应结果保持未知。

删除覆盖应用管理的数据及会话，不删除用户原始导出文件、外部备份或模型服务已经收到的内容；不宣称磁盘取证级安全擦除。桌面与 CLI 不应同时写同一 Home。

EEG／SleepGPT、临床、其他可穿戴设备、自动同步、长期基线、个人多晚实验和复杂报告管理器按路线暂缓。
