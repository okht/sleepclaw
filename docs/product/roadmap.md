# SleepClaw 产品路线

2026-09-21 批准。本文件覆盖历史方案中冲突的决定。旧代码和规格保留在历史开发仓库供追溯；本公开仓库包含当前 Pi 应用，不引入旧 Runtime。

| 阶段 | 用户获得什么 | 范围 |
| --- | --- | --- |
| 1 | 完成一次有用的睡眠调查 | 自述或苹果原始 ZIP／XML；逐题建档；读数据与追问交替；报告、一条行动及本地历史 |
| 2 | 慢慢找到适合自己的办法 | 个人基线、阶段复盘、相似睡眠对照、行动效果和个人睡眠实验 |
| 3 | 每天用起来更省事 | 增量导入／同步、可选提醒、更方便的记录入口及按需求增加设备 |
| 4 | 加入 EEG 深度分析 | MAT／EDF、质量检查、经过验证的模型估计分期；EEG 单独或联合分析；独立查看工具后续实现 |

## 保持不变的产品约定

- 面向普通用户，中英文同步。轻量桌面界面为主，CLI 共用核心能力。
- 用户连接自己的模型服务，Pi 负责模型执行、工具、流式输出、会话、取消与压缩。
- 没有设备也能用。整段睡眠、午睡、睡眠片段都可以分析，结论范围由实际数据决定。
- 基础问卷每次只问一题；动态追问后可以重新查数据；跳过表示未知。
- 禁用全部 Skills 仍可完成核心流程；第三方 Skills 为可选的 Pi 兼容扩展。
- 本机单用户保存，不强制加密健康记录；密钥单独保护；不启用遥测或自动更新服务。
- 报告区分计算结果、自述和 AI 解读；不提供诊断，不宣称已获医学验证。
- 分数只能作为初步参考。缺失项不记零，未完成验证的评分映射不输出分数。

## 第一阶段暂缓

EEG／SleepGPT、临床／研究工作流、Evidence 发布系统、自动同步、其他可穿戴设备适配、技能商店、复杂报告管理器及自动下载安装更新。

## 与旧方案的关系

本路线与 phase-1.md 覆盖旧版 Grok／ClawCode 底座、仅后端优先、强制加密、EEG 首发和临床首发的安排。沿用已确认的 Logo 与设计基础。项目停用 Superpowers、grill-powers、Kami 和 i-have-adhd。
