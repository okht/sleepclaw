# Desktop appearance update · 2026-09-21

## Confirmed direction

- Remove the white Windows title strip. The drag region blends into the application canvas, without a separate surface, border, or shadow.
- Retain native minimize, maximize, close, resizing, and Windows snap support through Electron's window-controls overlay.
- Keep the owl artwork unchanged. The SleepClaw wordmark has its own display face and restrained coral-to-teal treatment, informed by the supplied OpenClaws screenshots.
- Follow cht.me for the remaining typography: restrained text faces and a small set of weights. The local reference uses GT Eesti Text at 400, 500, and 700; it does not define a separate Chinese font.
- Do not change model, investigation, health-data, or report behavior during this appearance pass.

## Typography and distribution

The wordmark uses bundled Unbounded. Text prefers the user's already-installed GT Eesti Text family through `local()` declarations; this was verified in Chromium's actual rendered-font report. The checked-out cht.me assets are Trial fonts and have **not** been copied into SleepClaw or its installation package.

Inter and Noto Sans SC remain the bundled offline fallback for other computers. Chinese text was verified as Noto Sans SC. Bundled font assets are below 5 MiB and retain their OFL licenses. Matching GT Eesti on other computers requires suitable font files and embedding/distribution authorization; this remains a separate release decision.

## Implemented details

- A 40 px transparent drag region, native-controls safe area, and clickable language/theme controls.
- Theme changes update the native button colors via a narrow, validated main-process message; the Agent worker does not receive window commands.
- The sidebar surface extends to the top of the window; the connection page background is continuous behind its drag region.
- Connection content owns its own scroll region, so long forms remain accessible without moving behind the fixed window controls.
- Local fonts, clearer headings, consistent line icons, deeper card surfaces, and calmer spacing.
- UI-test Electron data lives under an explicitly selected test home. Tests do not reuse the user's production single-instance lock or browser storage.
