# SleepClaw Pi implementation

- Use PowerShell 7 (`pwsh.exe`), Chinese corner quotes 「」, and preserve unrelated changes.
- Superpowers, grill-powers, Kami and i-have-adhd are disabled for this project.
- Active implementation is `pi-app/`. Old runtimes are historical and excluded from its build.
- Pi owns model execution and sessions. Domain calculations must be deterministic and tested.
- Never log credentials or upload Apple Health archives. Tests use synthetic data only.
- Use apply_patch for authored files. Do not commit builds, databases, user records or dependency folders.
